## autowt switch

Switch to or create a worktree for the specified branch

```
autowt switch [branch] [flags]
```

### Options

```
      --after-init string      Command to run after session_init script completes
      --custom-script string   Custom script to run with arguments
      --dir string             Directory path for the new worktree
      --from string            Source branch/commit to create worktree from
  -h, --help                   help for switch
      --ignore-same-session    Always create new terminal, ignore existing sessions
      --terminal string        How to open the worktree terminal (tab, window, inplace, echo, vscode, cursor)
```

### Options inherited from parent commands

```
      --debug   Enable debug logging
  -y, --yes     Automatically confirm all prompts
```
